AMEVA-Forge vs PyTorch Comparison

AMEVA-Forge is designed with full PyTorch API compatibility in mind, but targets browser-first WebGPU execution rather than server-side CUDA.

Feature Comparison Table

Dimension PyTorch (Standard) AMEVA-Forge (Release 1.0)
Runtime Target Native OS (Linux/Windows/macOS), CUDA, ROCm Web Browsers (WASM + WebGPU), CPython, Node.js
Installation Footprint ~2-5 GB (CUDA binaries + torch wheel) < 500 KB (WASM + WGSL shaders)
Installation Speed Minutes (requires pip, driver configuration) Instantaneous (Zero-install web page)
API Syntax import torch, torch.nn, torch.optim import forge as torch, torch.nn, torch.optim
Autograd Engine C++ ATen Tape Autograd Dynamic Python + WebGPU Graph Autograd
Memory Management CUDA Caching Allocator Staging & Uniform Pool + Weakref Finalizers

Syntax Parity Example

# ── PyTorch Native Code ──
import torch
import torch.nn as nn

linear = nn.Linear(4, 2).cuda()
out = linear(torch.randn(1, 4).cuda())
loss = out.sum()
loss.backward()

# ── AMEVA-Forge Code (100% Identical!) ──
import forge as torch
import forge.nn as nn

linear = nn.Linear(4, 2).to('gpu')
out = linear(torch.randn((1, 4), device='gpu'))
loss = out.sum()
loss.backward()
