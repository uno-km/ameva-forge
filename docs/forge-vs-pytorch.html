The PyTorch Compatibility

If you're migrating from PyTorch, the transition is essentially zero-friction. Notice the identical API surface:

PyTorch:

import torch
import torch.nn as nn
import torch.optim as optim

model = nn.Sequential(nn.Linear(2, 4), nn.ReLU())
opt = optim.Adam(model.parameters(), lr=0.01)

AMEVA-Forge:

import forge as fg
import forge.nn as nn
import forge.optim as optim

model = nn.Sequential(nn.Linear(2, 4), nn.ReLU())
opt = optim.Adam(model.parameters(), lr=0.01)
