API Reference

Comprehensive reference for all core classes and functions exported by forge in Release 1.0.

1. forge.Tensor

Method / Property Description
forge.tensor(data, device='cpu', requires_grad=False) Creates a tensor from numpy arrays or nested lists.
forge.randn(shape, device='cpu', requires_grad=False) Creates a tensor with standard normal distribution.
tensor.to(device) Transfers tensor state between 'cpu' and 'gpu'.
tensor.backward(gradient=None) Accumulates reverse gradients into tensor.grad.
await tensor.realize() Forces execution of lazy GPU computation graphs.
await tensor.numpy_async() Asynchronously reads back GPU tensor data to a NumPy array.
tensor.dispose() Immediately frees associated GPU buffers and returns quota.

2. forge.nn Modules

Module Description
nn.Linear(in_features, out_features, bias=True) Fully connected linear transformation layer.
nn.LayerNorm(normalized_shape, eps=1e-5) Layer normalization across feature dimensions.
nn.BatchNorm2d(num_features, eps=1e-5, momentum=0.1) Batch normalization with running mean and variance tracking.
nn.PositionalEncoding(d_model, max_len=5000) Sinusoidal positional encoding with bounded LRU tensor cache.
nn.Dropout(p=0.5) Deterministic or pseudo-random dropout masking.
nn.Sequential(*layers) Sequential container of neural network modules.

3. forge.functional (F)

Function Description
F.scaled_dot_product_attention(q, k, v, is_causal=False) Scaled dot-product attention with optional causal triangular masking.
F.softmax(x, axis=-1) Numerically stable softmax activation along specified axis.
F.log_softmax(x, axis=-1) Numerically stable log-softmax using max-subtraction.
F.cross_entropy(predictions, targets) CrossEntropy loss with closed-form $(P - Y)/N$ backward gradient.
F.relu(x) Rectified linear unit activation function.

4. forge.optim

Class Description
optim.SGD(params, lr=0.01) In-place stochastic gradient descent optimizer using WebGPU AXPY kernel.
