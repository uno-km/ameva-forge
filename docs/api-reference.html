API Reference

This document details the primary public interfaces exposed by AMEVA-Forge v2.0.

Module: forge

forge.tensor(data, requires_grad=False, dtype=None)

Constructs a Tensor from a Python list or NumPy array.

  • data: Array-like object containing numerical data.
  • requires_grad (bool): If True, operations on this tensor are tracked by the Autograd engine.
  • dtype: Data type configuration (default: forge.float32).

forge.randn(shape, requires_grad=False)

Generates a Tensor populated with values from a standard normal distribution (mean=0, variance=1).

forge.zeros(shape) / forge.ones(shape)

Generates a Tensor populated exclusively with scalar 0.0 or 1.0 values, respectively.

Module: forge.nn

Contains layers and loss functions for building neural network architectures.

nn.Module

Base class for all neural network modules. Custom architectures should inherit from this class and implement the forward() method.

nn.Linear(in_features, out_features, bias=True)

Applies a linear transformation to the incoming data: y = xA^T + b.

nn.ReLU() / nn.Sigmoid() / nn.Tanh()

Standard non-linear activation functions.

nn.MSELoss()

Computes the mean squared error between network outputs and empirical targets.

Module: forge.optim

Implements standard optimization algorithms for gradient descent.

optim.SGD(params, lr=0.01)

Standard Stochastic Gradient Descent optimization.

optim.Adam(params, lr=0.001, betas=(0.9, 0.999))

Adaptive Moment Estimation (Adam) optimizer. Recommended for standard deep learning workflows.
