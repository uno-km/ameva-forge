What is AMEVA-Forge?

AMEVA-Forge is a specialized deep learning framework designed to bridge the gap between Python syntax and Browser execution.

Core Concepts

1. WebGPU First

Instead of relying on CUDA or server-side GPUs, AMEVA-Forge compiles its tensor operations down to standard WebGPU Shader Language (WGSL). This allows your Python code to tap directly into the user's local GPU from inside the web browser.

2. Pyodide Integration

Through Pyodide (CPython compiled to WebAssembly), AMEVA-Forge can run pure Python code directly in the browser. You do not need to rewrite your training logic in JavaScript or TypeScript. Just import the library and run.

3. PyTorch-like API

If you know PyTorch, you already know AMEVA-Forge. The API for Tensor, nn.Linear, optim.SGD, and backward propagation provides a PyTorch-like interface for basic MLP training.

4. Autograd Engine

AMEVA-Forge includes a robust, iterative automatic differentiation engine capable of processing deep computation graphs without recursion errors, supporting 2D matrix multiplications, ReLU activation, and MSE loss gradients for small MLP models.

Why build a browser framework?

Running models in the browser means zero server-side compute costs for inference and fine-tuning. It guarantees data privacy since user data never leaves their local machine, while still providing GPU acceleration.
