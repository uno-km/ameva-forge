Installation Guide

AMEVA-Forge Release 1 introduces basic MLP training workflows bridging standard Python and Browser environments. We outline installation procedures for both architectures below.

1. Standard Python Environment (CPU/NumPy Backend)

For server-side or desktop environments, AMEVA-Forge operates via its robust CPU backend, optimizing operations leveraging native NumPy kernels.

Prerequisites

  • Python 3.9 or higher
  • pip (Python package installer)

Installation Command

Execute the following command in your terminal:

pip install ameva-forge

Verify the installation via Python interactive shell:

import forge as fg
print(f"AMEVA-Forge Version: {fg.__version__}")
# Output: AMEVA-Forge Version: 0.1.0

2. Browser Environment (Pyodide & WebGPU)

To execute operations in a browser context leveraging local GPU acceleration, AMEVA-Forge utilizes Pyodide (WASM) alongside our WebGPU bridge.

Prerequisites

  • A modern web browser supporting WebGPU (e.g., Google Chrome 113+, Microsoft Edge 113+)

Implementation

Embed the requisite scripts within your HTML document. Ensure both the Pyodide runtime and the AMEVA-Forge bridge are initialized.

<!-- 1. Load Pyodide -->
<script src="https://cdn.jsdelivr.net/pyodide/v0.25.0/full/pyodide.js"></script>

<!-- 2. Load AMEVA-Forge WebGPU Bridge -->
<script>var exports = {};</script>
<script src="https://cdn.jsdelivr.net/npm/@ameva/forge@0.1.0/dist/index.js"></script>

<!-- 3. Initialize Environment -->
<script>
    if (exports.registerPyodideBridge) {
        exports.registerPyodideBridge();
    }
    
    async function initEnvironment() {
        const pyodide = await loadPyodide();
        await pyodide.loadPackage("micropip");
        const micropip = pyodide.pyimport("micropip");
        
        // Install the Python wheel
        await micropip.install("ameva-forge==0.1.0");
        
        // Execute Python
        await pyodide.runPythonAsync(`
            import forge as fg
            print("WebGPU Backend Initialized.")
        `);
    }
    initEnvironment();
</script>
