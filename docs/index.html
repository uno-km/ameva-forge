Welcome to AMEVA-Forge

AMEVA-Forge is a PyTorch-like WebGPU training framework built natively for Python and browser environments via Pyodide.

Getting Started

You can use AMEVA-Forge in two primary environments:

1. Browser (Pyodide & WebGPU)

Running deep learning models entirely in the browser without server-side processing.

import asyncio
from forge.device import init
await init()

import forge as fg
x = fg.randn((32, 128))
print(x.shape)

See our Benchmark Playground for a live interactive demo that automatically fetches and runs remote Python files without user uploads.

2. Python Environment (CPU/NumPy Fallback)

Use standard Python (3.9+) on Windows, Linux, or macOS.

pip install ameva-forge

Features

  • PyTorch-like API: Familiar API including Tensor, nn.Module, and optim.
  • Autograd: Fully functional reverse-mode automatic differentiation.
  • Zero-Copy Operations: Efficient WebGPU memory management.
