AMEVA-Forge: Browser-Native WebGPU Deep Learning

AMEVA-Forge is a high-performance, mathematically rigorous deep learning engine engineered to train and execute neural networks directly inside web browsers using Pyodide and native WebGPU compute shaders.

⚡ Launch Interactive WebGPU Studio 🚀 Read Quickstart Guide

Release 1.0 Architecture Highlights

🐍 100% PyTorch Compatible

Drop-in compatibility with PyTorch syntax: torch.Tensor, nn.Linear, nn.LayerNorm, optim.SGD, and loss.backward().

⚡ Hardware-Accelerated WebGPU

Compiles reverse-mode autograd graphs into unified 8D broadcast WGSL compute shaders with 2D workgroup dispatching.

🔒 Zero-Leak Memory Isolation

Deterministic staging buffer pools, weakref garbage collection finalizers, and fault-isolated error scopes.

Quick Code Example

import forge as torch
import forge.nn as nn
import forge.optim as optim

# 1. Define 2-Layer MLP
model = nn.Sequential(
    nn.Linear(2, 8),
    nn.ReLU(),
    nn.Linear(8, 1)
).to('gpu')

# 2. In-Place GPU SGD Optimizer
optimizer = optim.SGD(model.parameters(), lr=0.05)

# 3. GPU Forward & Backward Pass
x = torch.randn((4, 2), device='gpu')
y = torch.tensor([[1.0], [0.0], [1.0], [0.0]], device='gpu')

optimizer.zero_grad()
loss = torch.mean((model(x) - y) ** 2)
loss.backward()

# 4. Async In-Place Weight Update
await optimizer.step_async()
print("GPU Training Step Complete!")
