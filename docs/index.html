Welcome to AMEVA-Forge (Release 1)

AMEVA-Forge (Technical Preview) is a lightweight deep learning framework engineered for educational purposes and small model experimentation across both native Python environments and modern web browsers via WebGPU.

Release 1 Scope: 2-Layer MLP

Our current Release 1 focus is laser-targeted on one goal: Enable users to build, train, and understand a 2-layer Multi-Layer Perceptron (MLP) entirely in the browser using Python.

Core Capabilities

  • PyTorch-like API: Provides a familiar API surface to PyTorch for easy learning.
  • Browser Execution: Empowers basic deep learning operations to run purely client-side utilizing Pyodide and WebGPU without server latency.
  • Autograd Engine: Implements reverse-mode automatic differentiation for neural network topologies.

Supported Operations

  • Core: `tensor`, `upload`, `readback`, `dispose`
  • Math: `add`, `sub`, `mul`, `div`, `neg`, `matmul` (2D)
  • Activations: `relu`
  • Training: SGD Optimizer, basic Autograd

Note: Advanced vision modules (Conv2d, Pooling), RNNs, and Transformers are excluded from this Technical Preview to ensure mathematical parity and stability of the core engine.
