Welcome to AMEVA-Forge

AMEVA-Forge v2.0 is an enterprise-grade deep learning framework engineered for high-performance tensor operations across both native Python environments and modern web browsers via WebGPU.

Core Capabilities

  • Native PyTorch Compatibility: Provides a 1:1 identical API surface to PyTorch, enabling zero-friction migration of existing models.
  • Browser Execution: Empowers deep learning models to run purely client-side utilizing Pyodide and WebGPU without server latency.
  • Autograd Engine: Implements robust, graph-based automatic differentiation for arbitrary network topologies.

Getting Started

Proceed to our Installation Guide to set up AMEVA-Forge in your environment, or explore the Quickstart Guide to begin defining computation graphs immediately.

To experience the WebGPU integration without local setup, visit the Benchmark Playground.
