Quickstart Guide

This guide provides a rapid introduction to defining a neural network, performing forward passes, backpropagation, and updating weights using AMEVA-Forge v2.0.

1. Tensor Creation and Operations

AMEVA-Forge's fundamental data structure is the Tensor. Tensor operations are recorded dynamically for automatic differentiation.

import forge as fg

# Define standard tensors
x = fg.tensor([[1.0, 2.0], [3.0, 4.0]], requires_grad=True)
y = fg.tensor([[5.0, 6.0], [7.0, 8.0]])

# Matrix multiplication
z = x @ y
print("Forward Result:", z.data)

2. Automatic Differentiation (Autograd)

AMEVA-Forge v2.0 implements a highly optimized reverse-mode automatic differentiation engine. Calling .backward() computes gradients for all descendant tensors where requires_grad=True.

# Compute a scalar loss
loss = z.sum()

# Execute reverse accumulation
loss.backward()

print("Gradient of x:", x.grad)

3. Building a Neural Network

The forge.nn module provides a PyTorch-compatible API for constructing complex neural architectures.

import forge.nn as nn
import forge.optim as optim

class SimpleMLP(nn.Module):
    def __init__(self):
        super().__init__()
        self.fc1 = nn.Linear(2, 4)
        self.relu = nn.ReLU()
        self.fc2 = nn.Linear(4, 1)
        
    def forward(self, x):
        x = self.fc1(x)
        x = self.relu(x)
        x = self.fc2(x)
        return x

model = SimpleMLP()
print(model)

4. Training Loop

Integrating the model with an optimizer allows for standard training loop implementations.

# Define inputs and target
inputs = fg.randn((10, 2))
targets = fg.ones((10, 1))

# Initialize Optimizer and Loss Function
optimizer = optim.Adam(model.parameters(), lr=0.01)
criterion = nn.MSELoss()

# Single training step
optimizer.zero_grad()
outputs = model(inputs)
loss = criterion(outputs, targets)

loss.backward()
optimizer.step()

print(f"Step Loss: {loss.item()}")
