How AMEVA-Forge Executes in Browser

⚡ Pyodide WASM Runtime

Compiles standard CPython into WebAssembly, enabling PyTorch syntax without server-side compute.

🛡️ Direct WebGPU Shaders

Compiles computation graphs into 8D broadcast WGSL compute shaders with 2D workgroup grids.

🔒 Zero-Leak Quota Pool

GPU staging buffers and uniform memory are deterministically managed and reclaimed.
